# Company SOP Map

Test version of the company SOP website: a clickable workflow map that drills down to the SOP document for each step.

- `index.html` is the map. Open it in a browser.
- `sops/` holds the standardized SOP pages (SOP-PRD-000 Job Start Steps, SOP-PRD-001 PreSite).

This repo is private because the SOPs are internal. Logins and role-based permissions come in the full build.
