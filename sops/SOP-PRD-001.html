7. Procedure

Write the process as numbered, actionable steps. Use one primary action per step and identify the responsible role, required inputs, and expected result.

  1. Field Managers Monitor their assigned tasks by viewing their assigned task schedule.

The steps in the Presite Process are below:

  1. AP-IP:

    1. Open the contract, review details for buildability.

    2. Confirm pan dimensions if a custom pan and post a note on the message board for the PCs when they do the job order. This needs to be verified by comparing the job photos in the contract against the sold Tub/ Pan dimensions

    3. Once all the details in the contract are understood, open the corresponding par sheet by navigating to the job file in Dropbox. This can be found in Jacuzzi Open > Job Name > FINAL COSTING CONTRACTS SPECIAL QUOTES. The costing file is an excel named: Last name Costing Estimators Initials
      Ex: Smith Costing MP

    4. If there is anything found that is sold on the contract but is not in the pricing it must be added via the After Presite colum

  1. Once the Field manager has added or removed all of the necessary items. They will SAVE AS and add the following tag to the end of the file name (Bathroom Location-AP-IP-User Initials)
    EX: Smith Costing MP (JU-AP-IP-LL)

  2. Check with warehouse that all materials for the job are in stock.

  1. Pre-Order Survey Call to Customer.

    1. Field Manger Calls customer to talk over the details of the project.

    2. As they review the project, if there is anything that is missed, they note it down and make adjustments to the par sheet as mentioned before.

    3. If there is something that the customer wants to add to the project. They then generate a Change Order for signature.
      See the procedure for Change Orders in the link below:
      [LINK TO CO PROCESS]

    4. Field Manger verifies that there are no other job expectations.

    5. Confirm Scheduled Install Date if stock materials move install as soon as possible after recission period.

  2. Assign installer: Clock the installer task on the schedule. See below:

    1. This will open the task details on the right side of the screen


b. Search for the vendor in by clicking Add an Assignee. Once the installer is selected. Make sure to click at the top right of the screen. This will add the installer to the overall install schedule.

  1. Complete AP:

    1. Enter any additional information into the Par Sheet, then SAVE AS and change the file name to (Bathroom Location-AP-DONE-Uder Initials)
      EX: Smith Costing MP (JU-AP-DONE-LL)

    2. If the AP change is over $300, notify Admin by email that the change was made by using the following subject line: Smith 12345 JU AP Done.

      1. Make sure to let Admin know that the costing for your changes are in the par sheet.

    3. Check off your schedule items using the check boxes on the schedule. See below:

      1. Note: There are sub check boxes that MUST be also checked under each line which serve as the steps to follow for each task.
        [PROCESS END]
